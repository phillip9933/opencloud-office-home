# Security policy

## Supported versions

Office Home is in beta. Security reports for the latest beta and current `main` branch are welcome.
No guaranteed security response time is offered. The tested
OpenCloud baseline and outstanding dependency findings are documented in
[compatibility](docs/compatibility.md) and [dependency status](docs/dependency-status.md).

## Report a vulnerability

Use GitHub's **Report a vulnerability** action on this repository's
[Security advisories page](https://github.com/phillip9933/opencloud-office-home/security/advisories)
to contact the maintainer privately. The repository owner, `phillip9933`, triages reports.

Include the affected commit, OpenCloud Web/editor versions, impact and a minimal reproduction using
synthetic data. Do not send passwords, tokens, private documents or an unredacted production dump.
Do not post vulnerability details in public issues or pull requests. If private reporting is
unavailable, open an issue asking only for a private contact route, without disclosing the finding.

Test only systems and resources you are authorized to use. Findings in OpenCloud or the editor
itself should also follow that upstream project's private reporting process. Coordinate disclosure
with the affected maintainers before publishing exploit details.
